# 🏠 家看护 - Home Watch

> 基于 OpenClaw 的 AI 智能家庭监控系统，通过模拟器连接米家摄像头，实现定时截图、AI 画面识别、个性化语音播报。

## ✨ 功能亮点

- 📸 **定时截图** — 自动连接模拟器，定时截取摄像头画面
- 🤖 **AI 识别** — 智能分析画面中的人物、场景、活动
- 🗣️ **语音播报** — 根据不同人群（小孩/老人/成人）生成个性化关怀语音
- 📋 **日志记录** — 每次巡检自动记录画面描述
- 🔄 **自动恢复** — 模拟器未启动时自动唤醒

## 📋 前置要求

- Windows 系统（PowerShell）
- [MuMu 模拟器](https://mumu.163.com/)（或其他安卓模拟器）
- 米家 APP 已安装并登录
- 米家摄像头已添加

> ⚠️ **模拟器分辨率必须设置为 1600x900（横屏模式）**

## 🚀 快速开始

### 1. 下载

```bash
git clone https://github.com/你的用户名/home-watch.git
cd home-watch
```

### 2. 安装

```powershell
pwsh .\scripts\install.ps1
```

安装脚本会自动：
- ✅ 检测 MuMu 模拟器路径
- ✅ 检查模拟器运行状态
- ✅ 检测 ADB 端口
- ✅ 创建配置文件
- ✅ 注册定时任务

### 3. 使用

对 OpenClaw 说：
```
启动家看护
```

## 🎯 播报策略

| 场景 | 策略 |
|------|------|
| 👧 小朋友玩耍 | 提醒写作业 |
| 👧 小朋友学习 | 静默不打扰 |
| 👴 长辈 | 嘘寒问暖 + 养生贴士 |
| 👨 成年人 | 自然问候，提醒休息 |

## ⚠️ 注意事项

- 仅支持米家 APP 和米家摄像头
- 模拟器分辨率必须为 1600x900
- ADB 端口每次重启模拟器后可能变化（脚本会自动检测）
